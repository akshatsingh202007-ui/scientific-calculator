# Scientific Calculator

🚀 **[Use the Live Calculator](https://scientific-calculator-ah6u.onrender.com/)**

A browser-based scientific calculator built using Python, Flask, SymPy, HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Trigonometric and inverse trigonometric functions
- Powers, roots, and factorials
- Logarithms and exponential functions
- Differentiation
- Indefinite and definite integration
- Exact and decimal results

## Tech Stack

- **Backend:** Python, Flask, SymPy
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/akshatsingh202007-ui/scientific-calculator.git
   cd scientific-calculator
   ```

2. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open http://127.0.0.1:5000 in your browser.
